## Installation Workflows

### Universal Package Detection
```bash
# Intelligent input analysis
Input Types:
  - GitHub URL: https://github.com/user/mcp-server
  - NPM Package: @scope/package-name or package-name
  - PyPI Package: pip install package-name
  - Cargo Package: cargo install package-name
  - Known Server: Linear, GitHub, Playwright (from MCP.md)

Analysis Process:
  1. Analyze input type and repository structure
  2. Fetch README.md and package.json/pyproject.toml/Cargo.toml
  3. Extract installation commands and requirements
  4. Validate package availability on registries
  5. Generate optimal installation configuration
```

### Configuration Templates
```json
// NPM-based MCP Server
{
  "server-name": {
    "type": "stdio",
    "command": "npx",
    "args": ["-y", "package-name"],
    "env": {
      "API_KEY": "${API_KEY_VAR}",
      "LOG_LEVEL": "info"
    },
    "timeout": 30000,
    "restart": true
  }
}

// Python-based MCP Server  
{
  "server-name": {
    "type": "stdio", 
    "command": "uvx",
    "args": ["package-name", "--config", "~/.config/server.yml"],
    "env": {
      "PYTHONPATH": "/opt/mcp/lib"
    },
    "cwd": "/opt/mcp/servers/server-name"
  }
}

// SSE-based Remote Server
{
  "server-name": {
    "type": "sse",
    "url": "https://api.service.com/mcp/sse",
    "headers": {
      "Authorization": "Bearer ${API_TOKEN}",
      "User-Agent": "Claude-Code/1.0"
    }
  }
}
```

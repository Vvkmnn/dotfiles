## Performance Analysis Process

1. **Profile Current State**
   - Identify bottlenecks
   - Measure baseline metrics
   - Check time/space complexity
   - Review resource usage

2. **Analyze Code**
   - Look for:
     - Unnecessary loops (O(n²) that could be O(n))
     - Repeated calculations
     - Memory leaks
     - Blocking I/O
     - Inefficient data structures
     - Missing caching opportunities

3. **Propose Optimizations**
   Provide 3 specific improvements with trade-offs:
   
   **Optimization 1**: [Quick win]
   - Change: Specific code modification
   - Impact: Expected improvement
   - Trade-off: What we sacrifice
   
   **Optimization 2**: [Moderate effort]
   - Change: Algorithmic improvement
   - Impact: Performance gain
   - Trade-off: Complexity or memory
   
   **Optimization 3**: [Architectural]
   - Change: Design pattern shift
   - Impact: Scalability improvement
   - Trade-off: Implementation effort

4. **Validate Improvements**
   - Benchmark before/after
   - Verify correctness maintained
   - Document performance gains

Focus on measurable improvements with clear ROI.

# ChatGPT macOS and iOS

ChatGPT is one conversational/app surface in the AI family. The apps provide
notifications, mobile control, and GUI context when useful.

## Roles

- **ChatGPT macOS app:** fast conversation, screenshots, voice, desktop context.
- **ChatGPT iOS app:** approvals, remote monitoring, quick follow-ups away from
  the keyboard.
- **Codex.app:** local project host for Codex App, appshots, browser,
  Computer Use, worktrees, and remote pairing.
- **Codex TUI:** repo-editing interface when you choose Codex for the task.

## Setup gates

Complete these manually after install:

- Sign into ChatGPT and Codex with the same account/workspace.
- Enable notifications for ChatGPT and Codex.
- Pair ChatGPT mobile remote control from Codex.app when wanted.
- Grant Screen Recording for appshots only if you use them.
- Grant Accessibility for Computer Use only if you use it.

Do not store ChatGPT or Codex OAuth/session material in dotfiles.

## Operating policy

- Use ChatGPT for product thinking, writing, and mobile interaction.
- Use Codex for code, repo changes, verification, and machine setup when it is
  the right tool for the task.
- Prefer links/files/screenshots over retyping long context.
- Keep mobile remote control as a convenience layer, not a second source of
  configuration truth.
